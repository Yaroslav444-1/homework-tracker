# Трекер домашних заданий

Бесплатное офлайн-приложение для студентов: предметы с цветными бейджами, задания со сроками сдачи, наглядные индикаторы дедлайнов, светлая и тёмная тема.

- Без серверов, внешних API и регистрации — это статический сайт (SPA).
- Все данные хранятся в `localStorage` вашего браузера.
- Резервная копия и перенос между устройствами — кнопки «Экспорт в JSON» / «Импорт из JSON» внизу страницы.

Стек: Vite, React, TypeScript, Tailwind CSS v4, lucide-react.

## Локальный запуск

Нужен [Node.js](https://nodejs.org/) 20+.

```bash
npm install
npm run dev        # режим разработки: http://localhost:5173
npm run build      # сборка в папку dist/
npm run preview    # просмотр собранной версии
npm run dev:phone  # то же, что dev, но доступно с телефона в той же Wi-Fi сети
```

## Открыть на телефоне в домашней сети (быстро, без публикации)

1. На ПК запустите `npm run dev:phone`. В терминале появится строка `Network: http://192.168.x.x:5173/`.
2. Подключите телефон к той же Wi-Fi сети, что и ПК, и откройте этот адрес в браузере.

Если сайт не открывается: при первом запуске Windows может спросить, разрешить ли Node.js доступ к сети. Нажмите «Разрешить». Адрес работает, только пока ПК включён и команда запущена, а IP может смениться после перезагрузки роутера.

## Бесплатное размещение (сайт доступен везде, ПК не нужен)

Сборка использует относительные пути (`base: './'` в `vite.config.ts`), поэтому папка `dist/` работает и в корне домена, и в подпапке.

### GitHub Pages без установки git (проще всего)

1. Выполните `npm run build`. Появится папка `dist/`.
2. Создайте **публичный** репозиторий `homework-tracker`: https://github.com/new. Бесплатный GitHub Pages работает только с публичными репозиториями. В нём будет лишь код сайта, ваши задания хранятся отдельно, в приватном репозитории синхронизации.
3. На странице репозитория нажмите **uploading an existing file** (или **Add file → Upload files**) и перетащите **всё содержимое** папки `dist` (`index.html`, `favicon.svg`, `.nojekyll`, папку `assets`). Нажмите **Commit changes**.
   Файл `.nojekyll` скрыт в Проводнике. Чтобы его увидеть, включите «Вид → Показать → Скрытые элементы». Без него сайт тоже, скорее всего, заработает.
4. Откройте **Settings → Pages**. В **Source** выберите *Deploy from a branch*, ветку `main`, папку `/ (root)` и нажмите **Save**.
5. Через 1–2 минуты сайт откроется по адресу `https://<ваш-логин>.github.io/homework-tracker/` на ПК и на телефоне.

Чтобы обновить сайт после изменений в коде, снова выполните `npm run build` и загрузите новое содержимое `dist`. Старые файлы из `assets` можно удалить.

### Vercel / Cloudflare Pages

1. Загрузите проект в репозиторий на GitHub.
2. На [vercel.com](https://vercel.com) или в [Cloudflare Pages](https://pages.cloudflare.com) выберите «Import project» и укажите репозиторий.
3. Настройки: Framework — **Vite**, Build command — `npm run build`, Output directory — `dist`.

После каждого `git push` сайт будет пересобираться автоматически.

### GitHub Pages с автосборкой (нужен git)

В проекте уже есть [`.github/workflows/deploy.yml`](.github/workflows/deploy.yml): при каждом push в ветку `main` GitHub сам выполняет `npm ci && npm run build` и публикует `dist`.

1. Один раз: в репозитории откройте **Settings → Pages** и в поле **Source** выберите **GitHub Actions**.
2. После изменений в коде:

```bash
git add -A
git commit -m "Описание изменений"
git push
```

3. Через 1–2 минуты сайт обновится. Ход сборки виден на вкладке **Actions** репозитория.

## Важно про данные

Данные привязаны к конкретному браузеру и адресу сайта. Очистка данных браузера удалит задания, поэтому периодически делайте «Экспорт в JSON» или включите синхронизацию.

## Синхронизация между устройствами (GitHub)

Бесплатная синхронизация ПК ↔ телефон через ваш **приватный** репозиторий GitHub. Сайт обращается напрямую к `api.github.com`, других серверов нет.

1. Создайте приватный репозиторий, например `homework-data`: https://github.com/new.
2. Создайте Fine-grained токен: https://github.com/settings/personal-access-tokens/new
   - **Repository access** → *Only select repositories* → выберите этот репозиторий;
   - **Permissions** → *Contents* → *Read and write*.
3. На сайте: «Синхронизация» → «Настроить синхронизацию», введите `логин/homework-data` и токен.
4. Повторите шаг 3 на телефоне.

Как это работает:
- данные лежат в файле `homework-data.json` в репозитории, каждая синхронизация — отдельный коммит (это и есть история версий);
- изменения отправляются через 1,5 с после правки, а при открытии вкладки сайт подтягивает данные с других устройств;
- если правки были сделаны на двух устройствах между синхронизациями, сайт спросит, чьи данные оставить;
- подключить публичный репозиторий сайт не даст;
- токен хранится только в браузере устройства и не попадает в экспорт JSON. Не подключайте синхронизацию на чужих компьютерах. Если токен утёк, отзовите его на странице https://github.com/settings/personal-access-tokens.
